# Nana & Mimi — frontend

Frontend React/Vite da loja Nana & Mimi.

## Vercel
Configure a variável:
`VITE_API_URL=https://back-ahgw.onrender.com`

Sem `/` no final.

Comandos:
- `npm run build`
- `npm run dev`
